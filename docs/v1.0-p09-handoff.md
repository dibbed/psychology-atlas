## Actual defect found and fixed during P09 completion

A **direct-import circular dependency** was reproduced in a fresh Python interpreter:

```text
import atlas.cms_history_domains
  → imports atlas.cms_domains
  → cms_domains imports build_specs from partially initialized cms_history_domains
  → ImportError
```

Moved the shared `ProposalSerializer`/`_spec` import into `cms_history_domains.build_specs()` so import order does not affect behavior. Added `HistoryImportOrderTests` running both module-import orders in fresh subprocesses. The new test **failed before** the fix and **passed after** it. Public API and schema semantics were not changed.
