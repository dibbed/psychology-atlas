## Faults detected during independent regression and fixed

1. New P07 kind names with hyphens were incorrectly passed to P05 governance's underscore-named registered resources. The shared review dependency call now uses the explicit kind binding instead of propagating unknown resource names; source and rights stale-review checks pass.
2. `bounded_json()` returns `(normalized_text, parsed_document)` and refuses protected assessment material at a lower layer. P07 raw-read now correctly handles this return contract, rejects protected content with the expected safe response, and never discloses raw bytes to unauthorized DTOs.
3. P02 stale-write response was losing the submitted side of the three-way diff. Reconstructed conflicts again identify both the current and submitted changed fields without including private attempted values. Immutable review and persisted category/disorder revision semantics remain intact.
4. Review queue unknown filters and role-scoped reads were reconciled with P04/P07 contracts. Unknown query kind returns a bounded query error; a user with no Core/DSM read permission cannot list review records; direct unauthorized objects conceal their existence. Historical tests were updated where old expectations contradicted intentional P07 capability expansions, without removing protected-field guards or weakening historical audit decisions.
5. Historical P02 migration tests now use the historical ORM app state rather than a newer runtime ContentRevision model that contains the later `intent` column.
