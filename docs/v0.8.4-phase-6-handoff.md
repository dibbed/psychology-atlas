## PRESERVED_INVARIANTS

- A Session is a time window, not learning evidence. Browser QA showed Session completion left its Block pending; explicit reading confirmation completed a reading Block. Quiz, revision-bound Case, flashcard review, and distortion practice Blocks rejected completion before canonical activity and accepted it after their existing learning routes recorded evidence.
- Browser QA showed a single active Session through start, refresh, and Today resume. Equivalent active starts returned the same ID. The focused concurrency tests cover simultaneous equivalent/different starts, complete/abandon races, repeated terminal operations, stale exact-token replay, and the database partial unique constraint. A different UUID used only for active-state equivalence is not a durable alias, as frozen in the design contract.
- Today and Session reads remained owner-scoped and did not create canonical evidence. Legacy overview and Dashboard contracts, Recommendation V2 behavior, scheduler behavior, Case invariants, and scientific audits remained green in the full suite.
