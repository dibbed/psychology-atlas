# v0.8.4 Phase 4 handoff — Today Study API

Date: 2026-09-29. Branch: `feature/v0.8.4-today-study-sessions`.

## VERIFIED_FACTS

- `GET /api/study/today/` implements the frozen `docs/design-notes-v0.8.4.md` read contract. It captures one server time, uses the saved study timezone with an application-timezone fallback, and keeps Daily Challenge on its established application day.
- The selector returns one deterministic action in this order: active Session, resumable CaseAttempt, overdue Block, today Block, due SRS, available Daily Challenge with unscheduled headroom, visible Recommendation V2, then onboarding.
- Capacity uses all owned active Plans and today's eligible Block estimates. It does not use Session elapsed time or learning scores.
- The local SQLite database now has migration `0032_v084_study_sessions` applied; `PRAGMA integrity_check` returned `ok`. A pre-migration backup is at `backend/data/psychology_atlas.pre-0032-20260929.sqlite3`.

- `GET /api/study/overview/` and Dashboard retain their V1 recommendation response contracts. No frontend files changed in Phase 4.
