## 2026-11-11 | P17 internal research-key and exact-audit discovery, PARTIAL

Extended the existing independent `cms_search` endpoint with two additional closed, permission-scoped domains: `research` requires `cms_research_view` and indexes **only** `ResearchDataset.key` and `ResearchRecord.slug`; `audit` requires `cms_audit_view` and returns a row only for an **exact numeric event ID**, with no event-content or actor search. Both require the fresh CMS session and existing `cms_search` check; `domain=all` unions **only current permitted domains**. Research results expose kind/ID/key and optional dataset activity, never raw JSON, raw text, filename, source hashes, payload, translated names, external IDs or private content. Audit results expose kind/ID only, never actor, target, reason, event action, request ID, or diff. Returned identifiers are bounded by the existing per-kind 100-row search limit and 50-result page-size limit. Existing public search, public graph, P16 review/private data and canonical records were not modified.

Persian RTL `/admin-console/search` now shows domain options only when the corresponding capability is ready. Dataset/record/audit results link to the existing restricted detail pages. A request-generation fence discards old responses whenever users change the input, domain or unmount the page; no delayed research result can appear under an Audit selection.
